# Backend Practice 🚀

A collection of backend development practice programs using Node.js and Express.js.

## 🛠️ Tech Stack
- JavaScript
- Node.js
- Express.js
- REST APIs

## 🚀 Getting Started

```bash
git clone https://github.com/Nagesh-Soni/Backend_practice.git
cd Backend_practice
npm install
```

Start the server:

```bash
node server.js
```

Open `http://localhost:5000` in your browser.
